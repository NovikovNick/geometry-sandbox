◆ drawCombo()

template<typename T, typename... Items>
bool gs::drawCombo ( const char * label,
T & currentIndex,
Items &&... args )

Draws an ImGui combo box with items provided as variadic arguments.

Creates a dropdown combo box with the specified label and items. The current selection is stored in currentIndex. When the user selects a new item, the function updates currentIndex and returns true.

Template Parameters
TType of the currentIndex value (must be enum or integral type)
ItemsTypes of the variadic items (must be convertible to std::string)
Parameters
labelText label displayed next to the combo box
currentIndexReference to the current selection value, updated on user selection
argsVariadic list of items to display in the combo box
Returns
true if the user changed the selection, false otherwise
